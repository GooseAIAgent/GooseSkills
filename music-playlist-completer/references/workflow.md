# 第二部分：补全流水线（missing.json → 三级音源下载）

## 七、输入格式细节

### 网易云收藏歌单 CSV

网易云「收藏歌单」导出的 CSV 通常包含：歌名、歌手、专辑、时长（秒）、网易云链接（`https://music.163.com/song?id=NNN`）。`build_missing_list.py` 按列名模糊匹配（歌名/歌曲、歌手/艺术家、专辑、时长、链接/网易云链接/url），`id=` 自动提取为 `sid`。本技能第一部分输出的 `*-歌单完整清单.csv` 也可直接喂给 `build_missing_list.py`。

### m3u8

- `#EXTINF:245,歌手 - 歌名` 后跟本地路径 → 视为本地已有；
- 后跟网易云链接 → 提取 `sid`，视为平台条目；
- `# [本地无]` 之类的注释行自动忽略。

### missing.json 条目格式（三个下载脚本的统一输入）

```json
{"t": "歌名", "a": "歌手", "alb": "专辑", "dur": 245, "sid": "186001"}
```

- `dur` 单位秒，是版本校验的核心依据，务必保留。
- `sid` 为空时 `netease_dl.py` 会跳过该条（只走 QQ 搜索兜底）。

## 八、补全侧本地库比对口径

- 主键：`norm("歌手 - 歌名")` 标准化（去空白/标点/括号注释、转小写）。
- 文件名格式假定为「歌手 - 歌名.flac」；无 ` - ` 的文件退化为「歌名」键。
- 注意 CSV 里自带的「本地文件」列常有历史错配（同曲不同版本），**不要直接采信**，以实际扫描结果为准。
- 化名歌手（群星、未知、佚名、网络歌手）不算真实歌手，QQ 宽松档只按「时长差 ≤3s」锁定。

## 九、统计与交付口径

一次完整补全后，向用户报告应包含：

1. **覆盖率**：`（本地已有 + 各平台成功下载）/ 歌单总数`。
2. **音质构成**：从 `下载记录.jsonl` 汇总 FLAC/320k/128k 数量与总体积。
3. **待人工确认清单**：`版本待核对.jsonl`（时长差 >3s）+ QQ `match != 精确` 的条目（核心名/同歌手）。
4. **未获取清单**：分三类——
   - 原版受限，仅他人翻唱可下（未下载，附候选）；
   - QQ 有曲目但无版权（需付费/数字专辑）；
   - 同歌手版本仅现场/重录。
   每条附 QQ 候选（歌手/歌名/时长/可用音质），来自 `qq_probe.py` 输出的 `QQ候选对照.csv`。

## 十、m3u8 重建

路径全部变化后（如重新分类）必须重建并逐条校验：

```python
# 伪代码：先建索引（大小写不敏感），逐条 os.path.exists 校验后再写
idx = {}  # stem.casefold() -> abs path（递归扫描输出目录）
for x in playlist:
    p = x.get("local") or idx.get(safe(f'{x["a"]} - {x["t"]}').casefold())
    if p and os.path.exists(p):
        lines += [f"#EXTINF:{dur},{a} - {t}", p]
```

macOS 文件系统大小写不敏感但保留大小写，索引键用 `.casefold()` 防止「IU」vs「iu」这类漏配。

## 十一、并发与时长预算

实测参考（千首量级）：

| 阶段 | workers | 速度 |
|---|---|---|
| 网易云直下 | 4–6 | 约 20 首/18s（FLAC 平均 30MB） |
| 网易云替代 ID | 3 | 每首含搜索约 2–4s |
| QQ 兜底 | 3 | 每首含搜索+多 mid 试 vkey 约 2–5s |

超过 500 首建议分批跑并保留 `.jsonl` 记录，重跑幂等。

## 十二、下载后元数据补全（用户长期要求，每次下载后必做）

```bash
python3 scripts/enrich_meta.py --dir <音乐目录> --csv <全量清单.csv> [--newermt "YYYY-MM-DD"] [--force]
```

- **歌词**：网易云 `api/song/lyric` → 无歌词时 QQ 兜底（旧参数搜索，勿加 `new_json=1`；lyric 接口 base64 解码）。写入标签（FLAC `lyrics` / MP3 `USLT` / M4A `©lyr`）+ 同名 `.lrc` 侧车文件。
- **封面**：网易云 `api/v3/song/detail` 的 `al.picUrl`（旧接口返回 `album` 字段且常缺图，勿用），1500x1500 下载后写入标签（FLAC Picture / MP3 APIC / M4A covr），专辑目录无 cover.jpg 时另存一份。
- **基本标签**：title/artist/album 缺失时补全（B 站来源 m4a 常缺）。
- 幂等：已有歌词/封面的文件自动跳过；`--force` 重写。
- 网易云对纯音乐会返回「纯音乐，请欣赏」式元信息歌词，属正常。
- 无法匹配 CSV 的文件（如文件名自定义的 B 站来源）需用缺失清单里的 song id 手动补。
