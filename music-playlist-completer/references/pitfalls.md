# 踩坑手册（真实环境验证）

按排查优先级排列。遇到异常先查本文件，绝大多数问题都在这里出现过。

## 凭证获取

### 网易云：匿名只能 128k

匿名请求 `/api/song/enhance/player/url/v1` 只给 128k MP3。需要用户提供 cookie 中的 **`MUSIC_U`** 字段（VIP 账号可取 FLAC 甚至 24bit 高解析）。

### QQ：`qm_keyst` 和 `uin` 是 HttpOnly

用户在浏览器控制台执行 `document.cookie` **读不到**这两个字段，复制出来的只会是 `ptcz`、`_qimei_*`、`RK` 等埋点字段——这是最常见的凭证错误。正确引导话术：

> 方式 A（推荐）：打开 y.qq.com 确认已登录 → F12 → Network → 刷新 → 筛选 `musicu.fcg` → 点开任一请求 → Headers → Request Headers → 复制整行 `Cookie:`。
> 方式 B：F12 → Application → Cookies → `https://y.qq.com` → 找到 `uin`（形如 `o0123456789`）和 `qm_keyst`（形如 `Q_H_L_5xxx`）两行，分别复制。

### QQ cookie 组合的 A/B 结论

仅 `uin+qm_keyst`、加 `qqmusic_key`、`o` 前缀 uin、全量关键字段——四种组合鉴权结果**完全相同**。取不到无损时不要浪费轮次在 cookie 组合上，问题在账号权益（见下）。

## 网易云

### CDN 节点 403

部分节点（实测 m804、m704）返回 403，签名与主机无关可互换。脚本内置轮换 HOSTS 列表（m801/m802/m803/m701 优先）。若整批 403，检查 cookie 是否过期（重新让用户取）。

### 搜索接口限流

- `POST /api/search/get` 会返回 **405**，必须用 **GET `/api/search/pc`**；
- 即使 GET 也会限流，`netease_reid.py` 已内置 4 次退避重试（2.5s 递增）。搜索类操作不要调高并发。

### 标签误判（mutagen）

读取 FLAC 标签时**必须 `easy=True`**（如用 `FLAC(path)` 后再 `a.tags.get("album")` 会拿原始块名）。整理与下载联动时尤其注意：曾因此把 269 首「专辑全空」误判。

### 替代 ID 的版本陷阱

- 《轨迹》曾匹配到伴奏带：候选必须过 `VER` 正则（live/伴奏/inst/cover/remix…），歌单标题带版本词时要求候选版本词**布尔一致**。
- 《听海》在精选集而非原专辑：专辑名严格相等会漏，放宽为「歌名+歌手+时长差≤1.5s」；但放得多宽要在记录里写明，交付时列出。

## QQ 音乐

### `vkey` 请求必须带真实 uin

`CgiGetVkey` 的 `param.uin` 硬编码 `"0"` 时，VIP 无损**全部**失败。脚本从 cookie 解析真实 uin 注入。若用户报告「明明有会员但全拿不到」，第一查这个。

### 同一首歌有多条 mid

搜索结果里同一首歌常出现多条（不同合辑/专辑发行），**有版权的经常不是第一条**。`qq_dl.py` 对通过筛选的候选逐条试 vkey（最多前 3 条候选 × 3 档音质）。只试第一条会漏掉可下载的那条。

### 权益按版权方分级（104003）

会员状态有效 ≠ 全曲库可下。实测：

- ✅ 相信音乐、少城时代等曲库：绿钻直接取 FLAC；
- ❌ 部分大厂牌曲目（数字专辑/付费下载）：F000/M800/C400 全部返回 `result: 104003`；
- ✅ 用户**已购**的数字专辑可取无损。

处理：不要反复重试 104003，直接归入「QQ 有曲目但无版权」类，用 `qq_probe.py` 出候选清单交用户决策。

### 括号点名的歌手

歌单里常见 `歌名（一棵小葱+义掌柜）` 或 `歌名<阿悠悠>`，括号/尖括号里是**真实演唱者**。匹配时除主歌手外也要允许括号内容命中候选歌手，否则这些曲子全部误报「无匹配」。

### 时长标签差 1–5 秒

同一录音不同发行版本（加淡入淡出）时长常差 1–5s。精确匹配阈值为 5s、核心名匹配收紧到 3s 是平衡点；`--relax` 的结果永远要人工确认。

## 通用

### 文件头嗅探必须有

CDN 偶尔返回 HTML 错误页（Content-Type text/html 或 200 但 body 是页面），直接保存会得到假音频。所有落盘路径都先 `magic_ext()` 验文件头再 `os.replace`。

### `.part` 临时文件

下载中断会残留 `.part`，脚本在失败分支负责清理；交付前可 `find . -name "*.part"` 检查残留。

### 重名覆盖保护

目标文件已存在（任意音频扩展名）时跳过而非覆盖；如果需要覆盖，由用户明确指示后删除旧文件再下。

### 合规边界

本技能只下载用户**已在歌单中收藏**的曲目用于个人离线收听，不提供破解付费内容的能力；付费数字专辑拿不到就是拿不到，如实报告。
